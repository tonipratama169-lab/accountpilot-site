TikTok publishing

Creator authorization. Current settings. Explicit review.

AccountPilot's TikTok publishing flow is designed around creator awareness: connect an authorized creator account, select local media, refresh creator information, choose supported settings and submit only after the post package is reviewed.

Direct Post workflow

The selected creator and publishing choices stay visible.

AccountPilot uses the creator-selected local video for the configured FILE_UPLOAD workflow and keeps destination, caption, cover, privacy and supported interaction choices visible before Direct Post submission.

Review path

Open the public site, then launch the local desktop application.

AccountPilot Desktop must already be running on the review computer. The local application opens at 127.0.0.1:8000 and handles the creator workflow.
