Security

Local-first. Fail-closed. No hidden publishing.

Schedule Pilot is designed to stop execution when authorization, media integrity, creator capabilities, approval state or execution outcome is uncertain.

Authorized accounts

Publishing actions require platform authorization and the required scope for the connected creator.

Protected credentials

Normal application responses do not expose access tokens, refresh tokens, client secrets or signed upload URLs.

Duplicate prevention

A Direct Post publish identifier is durably recorded before media transfer. Ambiguous initialization is not automatically repeated.

Creator approval snapshots

Changing protected post fields invalidates prior approval and prevents stale packages from being armed.
