TikTok integration

How TikTok capabilities are used in Schedule Pilot.

This page describes the current creator-facing use of TikTok Login Kit, authorized account data and Content Posting API capabilities.

Login Kit

Creators connect and authorize their own TikTok account. Schedule Pilot uses the resulting authorization only for creator-approved capabilities.

Account identity & profile

user.info.basic and user.info.profile support connected identity and authorized profile context.

Creator analytics

user.info.stats supports account-level statistics used for creator insights and planning.

Recent public videos

video.list supports recent-public-video context for analytics and content planning.

Direct Post

video.publish supports creator-approved posting after preview, metadata selection, approval, scheduling and explicit consent.

Draft upload

video.upload supports sending content as a draft when the creator prefers to continue editing or posting inside TikTok.
