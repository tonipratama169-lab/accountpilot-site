TikTok publishing

Current creator information. Editable metadata. Explicit review.

AccountPilot's TikTok publishing flow is designed around creator awareness and the official Content Posting API: select the creator, select the local video, review supported choices and submit only after the post package is ready.

Local media transport

The selected file stays the selected file.

AccountPilot uses the creator-selected local video for the configured FILE_UPLOAD publishing workflow. The product does not require a separate phone-side media re-selection for Direct Post.
