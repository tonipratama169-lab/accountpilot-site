Creator insights

Account context for creator decisions.

Schedule Pilot uses only TikTok data that the creator has authorized. These permissions support identity, account insights and recent-content context before planning and publishing.

Basic identity

user.info.basic supports the connected creator identity such as open ID, avatar and display name.

Profile context

user.info.profile supports authorized profile fields such as username, bio/profile links and verification status.

Account statistics

user.info.stats supports creator-specific context such as follower, following, like and video counts.

Recent public videos

video.list supports recent public-video context for analytics, performance review and content planning.

Insights do not publish content.

Analytics and planning can inform recommendations, but final publishing remains a separate creator-controlled workflow with explicit post settings, approval and consent.
